## Character Relationship Map — Implementation Plan

A new page at `/characters/` rendering a fit-to-view relationship diagram: circular portrait nodes with names below, SVG edges colored by relationship kind, and a click-to-open dossier sidebar. All data sourced from `EarthiansCopyPlan.md` / `Earthians.md` / `lore.ts` (no fabricated lore; thin entries get the archive idiom "few facts filed").

### Design direction (per DESIGN.md)
Deep Archive register, dials ENERGY 2 / RHYTHM 2 / MOTION 1 (selection/hover transitions only, 0.2s, `prefers-reduced-motion` respected). Edge colors reuse existing tokens only: azure = personal bond, dashed slate = division/role, restricted-red = rival. Selected node + its edges are the single focus accent.

### Files

**1. `src/data/characters.ts` (new)**
```ts
interface DiagramCharacter { id, name, kind: 'earthian' | 'figure', no?, title?, faction?, excerpt }
interface Relationship { from, to, label, kind: 'bond' | 'division' | 'rival' }
export const characters, relationships
```
Roster (~38 nodes): the 12 `earthians` plus figures with a direct personal edge in the lore docs: companions (Kumiko Oumae, Yuno, Miyako, Akiizumi Momiji, Hatsuzuki, Itsuki Nakano, Kiryuu Kikyou, Theoto Rikka, Konoe Mina, Fu Xuan, Pamiat Merkuria, Yuzuriha, Liscia Elfrieden, Sunohara Kokona, Osakabehime, Ayumi Shinozaki, Rean Schwarzer, Voroshilov) and key figures (Anna Nishikinomiya, Hiyori Shiina, Chiyo Shimada, Hajime Tsukishima, Herminia Bertolini, Diane Cross, Black Maria, Isadora, Roroa Amidonia, Elizabeth Crowskin). Division rank-and-file (HOSC/Equilibrium/Team Icchi rosters) excluded per your curation choice. Each excerpt carries a source line in the beats doc.

**2. `src/lib/diagramLayout.ts` (new)**
Deterministic build-time layout, no libraries: hmgfan near center (he's the lore's hub), other Earthians on an ellipse around him, each figure fanned outward from their anchor Earthian, one deterministic collision-relaxation pass. Optional per-node `pos` override in the data file for fine-tuning. Canvas is a fixed viewBox (e.g. 1680×1050) scaled to container width.

**3. `src/components/RelationshipMap.astro` (new)**
- Diagram: server-rendered `<svg>` edges (data-from/to/label/kind) + HTML `<button>` nodes (portrait circle + mono name below). Not `<canvas>` — DOM nodes keep it keyboard-accessible and crisp.
- Nodes: Earthians get gold ring + archive-no badge; figures get azure/subtle ring. Portrait = `astro:assets` `<Image>` from `src/assets/characters/<id>.jpg` (via `import.meta.glob`, auto-picked-up when you drop files in; base-URL handled automatically) or an archival monogram placeholder (initials on bg-tertiary) when absent.
- Edge labels appear only for the selected node's edges (progressive disclosure; default view stays clean).
- Sidebar (right panel on desktop, styled like the existing `.nav-panel`): empty state "Select a node to open its dossier", then name, title/kind metadata, excerpt, faction, and connected characters as clickable chips (labels like "wife of", "leads HOSC for", "business rival of"). Escape closes; focus moves into it; `aria-pressed` on nodes.
- Character payloads embedded as one server-generated `application/json` island (single source of truth, light DOM).
- Inline processed `<script>` IIFE (FloatingNav pattern): selection, edge highlighting, sidebar population, Escape, canvas-click deselect, and `#char-<id>` hash deep-links on load.
- Mobile: diagram scrolls horizontally in a min-width wrapper; sidebar becomes a closable bottom sheet; 44px tap targets.

**4. `src/pages/characters/index.astro` (new)**
