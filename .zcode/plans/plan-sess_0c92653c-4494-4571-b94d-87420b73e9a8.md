## Implementation Plan: Page Load Animation & Loading States (DESIGN.md §7)

### Current State
Neither page load animation nor loading states are implemented anywhere in the codebase. Only basic CSS hover transitions exist (on cards and nav links). No `@keyframes`, no `animation`, no loading overlay, no pulsing text effect.

### Proposed Implementation

#### 1. Loading State Overlay — NEW FILE
**`src/components/LoadingOverlay.astro`** (new)
- Fixed, full-screen overlay div containing `"Decrypting Archive..."` text in monospace + `--text-secondary`.
- CSS pulsing animation: `opacity 0.5 → 1.0 → 0.5`, `1.5s` ease-in-out, infinite.
- Positioned at `z-[45]` (above scanlines at z-30, below nav at z-50).
- Fades out via CSS transition when `:root[data-loaded='true']` is set.

#### 2. Page Load Animation — Staggered fade-in-up
**`src/styles/global.css`** (edit)
- `@keyframes fade-in-up { from { opacity: 0; transform: translateY(0.625rem); } to { opacity: 1; transform: translateY(0); } }`
- `.animate-fade-in-up { animation: fade-in-up 0.4s cubic-bezier(0.16, 1, 0.3, 1) both; }`
- Staggered delay utilities: `.load-delay-0` through `.load-delay-6` (50ms increments).
- `:root[data-loaded='true']` trigger rules: the loading overlay fades out and the staggered animations on sections are activated.
- `prefers-reduced-motion: reduce` guard: disables all animations, sets `opacity: 1` and `transform: none`.

**`src/layouts/Layout.astro`** (edit)
- Insert `<LoadingOverlay />` right after `<body>` (before skip-link, FloatingNav, main).
- Add inline `<script is:raw>` that sets `document.documentElement.setAttribute('data-loaded', 'true')` on `window.load` (and immediately if `readyState === 'complete'`).

**`src/pages/index.astro`** (edit)
- Wrap each top-level section in a `<div class="animate-fade-in-up load-delay-N">` to achieve the staggered sequence:
  - HeroSection → `load-delay-0`
  - WorldStatusDashboard → `load-delay-1`
  - RegionsGrid → `load-delay-2`
  - EarthianRegistry → `load-delay-3`
  - InstitutionsGrid → `load-delay-4`
  - RestrictedArchives → `load-delay-5`
  - Footer → `load-delay-6`
- Also add `class="invisible"` on `<body>` initially, then `data-loaded` on `<html>` flips all to visible — OR rely on the `:root[data-loaded]` CSS to trigger animations from a hidden starting state. The animation itself starts from `opacity: 0` via the keyframe, so wrapping divs just need the animation class.

- No animation libraries needed — pure CSS `@keyframes` + vanilla JS.
- Tailwind v4 arbitrary value syntax works without config changes.
