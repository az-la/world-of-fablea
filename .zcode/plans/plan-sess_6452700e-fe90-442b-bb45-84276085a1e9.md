## Antislop Remediation Plan

### Context
The codebase was built with a "Vesper City archival database" aesthetic but contains several AI-generated design patterns flagged by the antislop rules. The user invoked `$antislop` and `$antislop-ui` skills and wants the UI cleaned up, plus image backgrounds from picsum.photos.

### Issues Identified (Antislop Violations)

1. **Excessive Glassmorphism (R-10)**: `backdrop-filter: blur(10px)` appears on StatusBadge, ArchiveCard, WorldMap region markers, legend items, dashboard cards. Fix: Remove blur entirely — keep cards solid with subtle borders.
2. **Badge Overuse (R-09)**: Badges appear on nearly every card and section. Fix: Reduce to archival metadata only (Archive number + Status), remove redundant badges.
3. **Uniform Template Layout (R-05)**: All sections follow identical `<container><header><content>` structure. Fix: Vary section structure — hero gets full-bleed image, dashboard gets split layout, registry gets tight grid.
4. **Copy-Paste Cards (R-14)**: All ArchiveCards are identical regardless of content type (currency vs region vs Earthian). Fix: Add `variant` prop for compact vs spacious treatment.
5. **Glow Everywhere (R-13, R-31)**: Hover glow on cards, glow on legend dots, glow in hero buttons. Fix: Remove all glow effects; elevation via shadow only.
6. **Generic Gradient (R-01)**: Hero uses radial gradient as background. Fix: Replace with picsum.photos maritime image + dark overlay.
7. **Missing Images**: No image backgrounds at all. Fix: Add picsum.photos for hero background and map texture.

### Files to Modify

1. **src/styles/global.css** — Replace full-page gradient with solid dark; establish spacing scale; remove default glow shadows
2. **src/components/StatusBadge.astro** — Strip backdrop-filter; simplify to border + muted background; keep variant system for status meaning
3. **src/components/ArchiveCard.astro** — Remove blur; add `variant` prop (default/compact/spacious); remove glow on hover; remove colored left stripe
4. **src/components/HeroSection.astro** — Add picsum.photos maritime background; reduce badges 3→2; tighten description to lore-accurate archival text

8. **src/pages/index.astro** — Add section-spacing variation between sections
